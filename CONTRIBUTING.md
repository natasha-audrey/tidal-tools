# Contributing

Thanks for taking the time to look at this repo! This project is very early in
development, so I am not currently accepting contributions. However, feel free
to create an [issue](https://github.com/natasha-audrey/tidal-tools/issues/new)
if you have ideas for a new feature, enhancement, or to report a bug.

## Commits and PRs

Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for
commit messages and PR titles. We use squash commits for PRs. This repo uses
[Release Please](https://github.com/googleapis/release-please) to automate releases.
